# Decision Trees

## Overview
Decision Trees are non-parametric models that learn simple decision rules inferred from data features. This module covers the creation, evaluation, and interpretability of tree-based models.

## Key Concepts Implemented
* **Tree Building**: Handling numeric and categorical data splits (using algorithms like CART).
* **Interpretability**: Extracting decision rules that are easy to understand compared to black-box models.
* **Overfitting awareness**: Recognizing that deep decision trees tend to overfit the training data unless pruned or restricted by depth constraints.

## Datasets Used
* `Iris.csv`
* `Titanic-Dataset.csv`
* `housing.csv`
