# Logistic Regression Projects

## Overview
Logistic Regression is the foundational algorithm for binary and multi-class classification. This folder showcases projects using Logistic Regression across both structured tabular datasets and unstructured text data.

## Real-World Projects Implemented
* **`spam_detection_tfidf.ipynb`**: Implements Logistic Regression for spam detection. Compares TF-IDF Vectorization against CountVectorizer to evaluate model precision and recall on email text data.
* **`logistic_regression_projects.ipynb`**: Contains multiple classification implementations including:
  * **Titanic Survival Prediction**: Predicts survival probability based on passenger demographics.
  * **Heart Disease Detection**: Binary classification for diagnosing the presence of heart disease based on medical indicators.
  * **Iris Classification**: Visualizes the mathematical decision boundaries drawn by the model separating flower species.

## Key Concepts Demonstrated
* Binary Classification (Spam/Ham, Survived/Not Survived).
* Text Processing (NLP) with TF-IDF Vectorization.
* Decision Boundaries plotting.
* Comprehensive Model Evaluation: Precision, Recall, F1-Score, and Confusion Matrix visualizations.
