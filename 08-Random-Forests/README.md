# Random Forests

## Overview
Random Forests build upon the concept of decision trees by creating an "ensemble" of many trees to improve predictive accuracy and control overfitting. This module demonstrates the robustness of bagging (Bootstrap Aggregating) techniques.

## Key Concepts Implemented
* **Ensemble Learning (Bagging)**: Creating multiple decision trees on random subsets of data and features, then aggregating their predictions.
* **Feature Importance**: Using the Random Forest model to determine which features have the strongest predictive power.
* **Model Stability**: Demonstrating how Random Forests achieve 100% training accuracy on datasets like Iris and generalize well on testing data without extreme overfitting.

## Datasets Used
* `Iris.csv`
* `Titanic-Dataset.csv`
* `housing.csv`
