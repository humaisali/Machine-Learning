# Naive Bayes Classification Projects

## Overview
Naive Bayes algorithms rely on Bayes' Theorem with an assumption of independence among predictors. It is particularly effective for large datasets and text classification. This folder contains various predictive projects utilizing the Multinomial Naive Bayes algorithm.

## Real-World Projects Implemented
* **`movie_sentiment_analysis.ipynb`**: Classifies movie reviews into positive or negative sentiments.
* **`email_spam_detection.ipynb`**: Analyzes email text properties to detect spam vs. ham.
* **`customer_purchase_prediction.ipynb`**: Predicts if a user will buy a product based on website visits, ad clicks, and demo watch data.
* **`diabetes_detection.ipynb`**: Uses medical indicator data to classify patients as having diabetes or not.
* **`loan_approval_prediction.ipynb`**: Predicts whether a customer's loan will be approved based on financial history.
* **`student_performance_prediction.ipynb`**: Predicts student pass/fail outcomes based on study metrics.
* **`language_detection.ipynb`**: Identifies the language of a given text snippet.
* **`play_tennis_prediction.ipynb`**: Uses weather conditions (Outlook, Temperature, Humidity) to predict if tennis can be played.
* **`cricket_match_outcome.ipynb`**: Predicts match results based on historical cricket statistics.

## Key Concepts Demonstrated
* Multinomial Naive Bayes model training and evaluation.
* Text & Contextual Analytics.
* Performance Comparisons (Accuracy, Precision, Recall, F1-Score) and Confusion Matrices.
