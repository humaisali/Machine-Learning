# Machine Learning Project Portfolio

Welcome to my Machine Learning repository! This project serves as a comprehensive portfolio of my journey in mastering Machine Learning concepts, algorithms, and practical applications. 

Moving beyond standard academic lab structures, this repository is organized professionally by core ML methodologies. **Inside each topic folder, you will find real-world predictive modeling projects** demonstrating hands-on implementation of that specific algorithm.

## Repository Overview & Projects

### 1. Core Data Preparation
* **[01-Data-Preprocessing](01-Data-Preprocessing/)**: Handling missing values, encoding categorical data (Label & One-Hot Encoding), and feature scaling using the Titanic dataset.
* **[02-Exploratory-Data-Analysis](02-Exploratory-Data-Analysis/)**: Statistical analysis, correlation heatmaps, data distribution visualization, and outlier detection.

### 2. Regression & Classification Projects
* **[03-Linear-Regression](03-Linear-Regression/)**: 
  * *California Housing Regression*: Predicting house prices.
  * *KPK Engineering Regression*: Predicting program employability based on university stats.
* **[04-Logistic-Regression](04-Logistic-Regression/)**: 
  * *Email Spam Detection*: Using TF-IDF vectorization.
  * *Heart Disease & Titanic Survival*: Binary classification models with decision boundary visualizations.
* **[05-Support-Vector-Machines](05-Support-Vector-Machines/)**: 
  * *SVM Decision Boundaries*: Visualizing Kernel tricks (RBF, Poly) and Grid Search hyperparameter tuning.

### 3. Probabilistic & Tree-Based Projects
* **[06-Naive-Bayes](06-Naive-Bayes/)**: 
  * Includes 9 separate projects such as *Movie Sentiment Analysis*, *Customer Purchase Prediction*, *Diabetes Detection*, *Language Detection*, and *Loan Approval Prediction*.
* **[07-Decision-Trees](07-Decision-Trees/)**: 
  * Tree building and rule extraction on datasets like Iris and Play Tennis.
* **[08-Random-Forests](08-Random-Forests/)**: 
  * Implementing Bootstrap Aggregating (Bagging) to improve predictive robustness and extract feature importance.

### 4. Advanced Boosting Projects
* **[09-Ensemble-Learning](09-Ensemble-Learning/)**: 
  * *Heart Disease XGBoost*: Feature importance extraction.
  * *Bank Marketing AdaBoost*: Handling class imbalance with sample weights and ROC-AUC curve plotting.
  * *California Housing XGBoost*: Hyperparameter grid search visualized via custom heatmaps.
* **[10-Final-Project](10-Final-Project/)**: 
  * An end-to-end predictive modeling capstone integrating multiple techniques.

## Tech Stack & Tools
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Machine Learning:** Scikit-Learn, XGBoost
* **Visualization:** Matplotlib, Seaborn
* **Environment:** Jupyter Notebooks
