# Exploratory Data Analysis (EDA)

## Overview
Before training any predictive model, it is critical to understand the underlying distribution and characteristics of the data. This module explores data profiling, summary statistics, and visual insights.

## Key Concepts Implemented
* **Descriptive Statistics**: Calculating the mean, median, and mode for numeric features to understand central tendencies.
* **Data Distribution Visualization**: 
  * **Histograms**: To check if the data follows a normal distribution or if it is skewed.
  * **Boxplots**: A standard way to display the distribution of data based on a five-number summary and effectively detect outliers.
* **Bivariate Analysis**:
  * **Scatter Plots**: Visualizing the relationship between two continuous variables (e.g., Age vs. Fare).
  * **Faceted Plots**: Breaking down distributions across different categorical groups.
* **Outlier Detection**: Using visual rules and standard deviations to isolate anomalies in the dataset.
